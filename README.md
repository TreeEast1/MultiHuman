# MultiHuman：多模态生理-行为信号驱动的操纵员认知工作负荷预测

> 基于 EEG（脑电）、心率、眼动、任务操作日志四模态数据，预测核电操纵任务下操纵员的主观工作负荷（NASA-TLX 加权总分）。
>
> **本仓库以"进度日志"方式组织**：最新进度在顶部，历史进度按时间倒序往下排。每次进度都记录"做了什么 / 结果如何 / 下一步"。

### 一、本次核心成果

1. **修复了一个隐性数据缺陷**：1002 号 EEG 原始文件时间截断错误（旧版仅 24 秒，新版完整 31 分钟），全量重跑 pipeline，数据集从 12 258 窗口更新为 12 624 窗口。详见 `工作目录/01_预处理/DATA_FIX_AUDIT.md`。
2. **敲定了特征方案的 5 个关键决策**（见"决策记录"一节），特征输入定为 66 列。
3. **搭建了建模评估框架**（`工作目录/03_建模/`）：`make_dataset.py` + `evaluate.py` + `baseline.py`，评估协议以 GroupKFold（按 sample_id 分组）为准，杜绝历史阶段的窗口级随机划分泄漏。
4. **跑通了 5 个 baseline**：均值预测 / 单变量线性 / 全特征线性 / RandomForest / XGBoost。**得到了本项目第一份没有数据泄漏的诚实基线结果**。

### 二、决策记录（特征方案）

| 决策项 | 结论 |
|---|---|
| **EEG 相对功率** | 暂不加。当前 28 列 EEG（4 脑区 × 5 频段 + 2 比值） |
| **EEG z-score vs 原始** | 建模输入用 28 个 z-score 版；28 个原始版 CSV 保留但不进模型 |
| **AOI 归类** | 9 列 AOI 全部进模型，但报告口径标注为"情境意识代理"（非负荷指标） |
| **日志 win/cum 取舍** | **只用 win 版**（12 列）；cum 系列因编码任务进度信息，作为特征保留但不进模型 |
| **主用窗口** | **30 s / step 5 s**，10 s 版本暂不用 |

**最终建模输入 = 66 列**：
- 28 列 EEG（被试内 z-score）
- 5 列心率
- 15 列眼动（6 瞳孔+注视 + 9 AOI）
- 6 列眨眼（过滤后）
- 12 列日志（仅 win）

### 三、评估协议（本项目一律遵守）

1. **划分单位**：`GroupKFold(n_splits=5, groups=sample_id)`，同一被试-任务的所有窗口只在同一折
2. **主指标（任务级）**：把测试折内每个 sample_id 的窗口预测取**中位数**聚合成 1 个数，与真值比对
3. **对照指标（窗口级）**：直接算 12 624 个窗口的 MAE / R²
4. **随机种子固定**：`random_state=0`
5. **缺失值处理**：
   - 线性 / RF：训练折内中位数填充（fit 时算、transform 到测试折，避免泄漏）
   - XGBoost：原生吃 NaN，不填充

### 四、结果一览

#### 4.1 5 个 baseline 对比（5 折 GroupKFold 均值 ± std）

| 模型 | **任务级 MAE ↓** | **任务级 R² ↑** | 窗口级 MAE ↓ | 窗口级 R² ↑ |
|---|---:|---:|---:|---:|
| MeanPredictor（零信息下限） | 1.325 ± 0.106 | -0.093 ± 0.072 | 0.956 ± 0.106 | -0.041 ± 0.029 |
| Linear_Single_FrontalThetaAlpha_z | 1.320 ± 0.102 | -0.078 ± 0.092 | 0.957 ± 0.108 | -0.040 ± 0.033 |
| Linear_AllFeatures | 1.267 ± 0.106 | -0.027 ± 0.205 | 1.014 ± 0.060 | -0.140 ± 0.091 |
| **RandomForest_default** | **1.170 ± 0.126** | **+0.126 ± 0.127** | 0.999 ± 0.089 | -0.107 ± 0.091 |
| XGBoost_default | 1.219 ± 0.134 | +0.019 ± 0.178 | 1.013 ± 0.093 | -0.149 ± 0.106 |

NASA-TLX 真值范围 [1.333, 7.800]，均值 5.370，std 1.238。

#### 4.2 两种评估口径的解读

- **任务级 R² = +0.126（RandomForest）** 是本项目当前的诚实基线。这表示模型在跨被试预测新样本的 NASA 总分上，能解释约 12.6% 的方差——**有信号，但还很弱**。
- **窗口级 R² 全部为负** 是**符合预期的现象**，不是模型失败：
  - NASA-TLX 是任务结束后一次性问卷评分（任务级真值），84 个任务只有 84 个真值
  - 12 624 个窗口共享的"真值"实际上是 84 个数各自复制若干次得到的常数
  - 模型对每个窗口给出的预测天然会围绕任务均值波动，窗口级 R² 惩罚这种波动，导致负值
  - **正确评估口径是任务级**（这也是文献主流做法：RAMC-Net 2026、飞行员 MWL 论文等）
- **窗口级 MAE 反而看起来"更好"**（0.956 vs 1.325）是数值假象：MAE 对小误差不敏感，而窗口级共享真值使得中心附近的窗口预测容易命中，掩盖了真实预测能力

#### 4.3 各模型解读

| 观察 | 含义 |
|---|---|
| RandomForest 显著优于 MeanPredictor（MAE 1.170 vs 1.325，改进 12%） | 66 维特征在跨被试预测 NASA 上确实包含有效信号 |
| Linear_Single ≈ MeanPredictor | 单一 EEG frontal θ/α 特征在跨被试场景下几乎无判别力（学到的斜率 ≈ 0） |
| Linear_AllFeatures 反而比单变量差 | 高维线性模型在 84 样本量下过拟合噪声，需要正则化 / 特征选择 |
| XGBoost 表现不如 RandomForest | 默认超参数（max_depth=5, n_estimators=300）在小样本高维下略过拟合，后续调参有空间 |
| 各折 std 都比较大（0.10–0.20） | 5 折中不同被试组合的可预测性差异明显，说明**存在个体异质性** |

### 五、与历史结果的对比与差距分析

**关键铁证**：历史项目自己做过一份"随机窗口划分 vs 样本级划分"的对照实验，位于 `历史工作_存档_20260703/package_nasa_random_window_regression_classification/original_results/nasa_window_label_random_window_vs_sample_split_quick5/window_split_summary.csv`。

同一份数据、同一批模型，仅仅因为划分方式不同：

| 划分方式 | ExtraTrees Macro-F1 | RandomForest Macro-F1 |
|---|---:|---:|
| **随机窗口划分**（有泄漏） | **0.998** | 0.990 |
| **随机样本划分**（正确，按 sample_id 分组） | **0.287** | 0.283 |

**F1 从 0.998 塌到 0.287**——这就是数据泄漏的量级。历史论文中出现的 XGBoost 回归 `R²=0.955` 数字，来自随机窗口划分实验，不能作为跨被试预测能力的证据。

**历史三套评估结果按严格度排序**：

| 评估口径 | 历史最佳结果 | 严格度 | 可信度 |
|---|---|---|---|
| ① 随机窗口划分（有泄漏） | XGB 回归 R²=0.955 / 分类 F1=0.951 | ❌ 有泄漏 | 不可信 |
| ② 任务级建模 + 5 折 CV（30 次重复） | RandomForest 回归 R²=0.736 / 3 分类 F1=0.807 | ⚠️ 未强制跨被试 | 中等可信 |
| ③ 早期 36 样本 NASA 回归（`stored report`） | 所有模型 R² 为负（-0.011 ~ -0.25） | ✅ Leave-one-subject | 可信但样本量太小 |
| ④ **本次基线（2026-07-07）** | **RandomForest 回归 R²=0.126（任务级）** | ✅ GroupKFold by sample_id | **可信** |

**为什么当前 R² 只有 0.126，与历史第 ② 套的 0.736 有差距？**

三个可能原因，需要后续实验区分：

1. **建模粒度不同**：历史 ② 套是"任务级建模"（把窗口特征聚合成 84 行），我们当前是"窗口级建模 + 任务级评估"。前者直接把统计特征喂给模型，后者要求模型从原始窗口出发学习。**下一步实验会补充任务级建模版本**。
2. **特征筛选差异**：历史用了信息量筛选（MI），从 58 特征筛到 16 特征。我们当前 66 特征未筛选，高维小样本下噪声占比偏高。
3. **历史 30 次重复划分可能仍有弱泄漏**：同一被试的不同任务可能分别落在训练和测试，被试个体基线信息透过训练集流入。严格的 Leave-One-Subject-Out 评估会进一步压低分数。

### 六、当前进度的诚实定位

- **✅ 数据基础扎实**：EEG 时长问题已修复；四模态时间对齐；特征方案附文献依据
- **✅ 评估协议正确**：GroupKFold 按 sample_id 分组，杜绝历史阶段的窗口级随机划分泄漏
- **✅ Baseline 有效但弱**：R²=0.126 证明特征在跨被试预测上有信号，但**离文献典型水平（R² 0.2-0.5）还有距离**
- **⚠️ 单一模型 vs 多模型对比清晰**：树模型 > 线性模型 > 零信息下限，验证特征非线性依赖存在
- **❌ 尚未做**：任务级建模对齐历史口径 / 特征筛选 / 超参数调优 / 消融实验 / 更严格的按被试划分（Leave-One-Subject-Out）

### 四、特征工程要点（每一项都附了文献依据）

- **EEG（28 原始 + 28 被试内 z-score）**：修复历史仅计算绝对功率的方法学漏洞，做全特征被试内 z-score，实测把 `frontal_alpha` 个体间方差占比从 69.7% 压到 0.0%
- **眼动（7 瞳孔+注视 + 9 AOI + 8 眨眼）**：补全历史缺失的眨眼代理特征，用 `EyesNotFound` 段（过滤 50-500ms）代替，实测眨眼频率中位数 10 次/分钟符合文献
- **心率（5 列）**：明确说明 4.6s 采样一次的瞬时心率无法做经典 HRV，历史方案没做 HRV 是数据格式决定的（不是遗漏）
- **日志（32 列 = 16 win + 16 cum）**：两套并存，通过后续消融决定取舍

## 快速上手

前提：Python 3.11+，安装 `numpy pandas scipy scikit-learn xgboost openpyxl`。

### 复现特征提取

```bash
cd 工作目录/01_预处理/scripts

python3 step1_build_window_samples.py \
    --data-dir ../../../data \
    --output-dir ../output_30s_step5s \
    --window-sec 30 --step-sec 5

python3 step2_add_log_features.py \
    --data-dir ../../../data \
    --index-csv ../output_30s_step5s/index.csv \
    --sample-dir ../output_30s_step5s/window_features_30s_step5s \
    --output-dir ../output_30s_step5s_with_log

python3 step3_blink_and_eeg_zscore.py \
    --input-dir ../output_30s_step5s_with_log \
    --eye-dir ../../../data/05_眼动/raw_tsv \
    --output-dir ../output_30s_step5s_final \
    --blink-min-ms 50 --blink-max-ms 500
```


## 工程规范

1. **数据源单一**：所有处理只从 `data/` 读取，不引用 `历史工作_存档_20260703/` 中的任何中间产物或特征结论
2. **每步留三样**：脚本 + 输出 + README；任何特征筛选决策必须交代依据
3. **窗口 / 预处理参数化**：便于跨粒度对比，禁止把窗口大小硬编码
4. **评估协议**：任何模型评估必须 GroupKFold 按 `sample_id` 分组，禁止窗口级随机划分
5. **弱标签如实标注**：不掩盖窗口预测本质是弱监督这一事实
6. **进度追加而非覆盖**：本 README 采用进度日志格式，新进度在顶部，旧进度不删
