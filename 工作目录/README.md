# 工作目录/ 说明

本目录是本项目**当前阶段的唯一工作区**。历史上所有的预处理脚本、特征工程逻辑、建模结果，全部封存在 `../历史工作_存档_20260703/`，**不再引用、不再作为依据**——包括其中的特征选择方案（如EEG只挑F4-beta/Oz-alpha两个指标），因为那些筛选缺乏明确交代的依据。

## 设计原则

1. 数据只从 `../data/` 读取。
2. 每一步处理都在这里留脚本+输出+说明，任何特征筛选决策都必须写清楚依据（统计检验/物理意义/前人文献），不能"直接抄历史结果"。
3. 窗口/预处理参数化，方便做多粒度对比（当前计划：10秒 与 30秒 两版窗口对比，理由见下）。

## 子目录

| 目录 | 用途 |
|---|---|
| `01_预处理/` | 从 `data/` 原始信号出发的对齐、切窗、聚合脚本与输出（EEG/心率/眼动/日志四模态统一时间窗对齐） |
| `02_特征数据集/` | 经过特征工程后、可直接喂给模型的表格数据集 |
| `03_建模/` | 训练脚本、评估协议(GroupKFold等)、结果记录 |

## 已达成的关键共识（供后续执行参照）

- **预测目标**：NASA-TLX 加权总分（任务级单一标签），旧综合S指标已废弃。
- **标签本质**：NASA-TLX 是任务结束后一次性问卷打分，不存在逐秒真值。窗口级预测本质是"用时间片特征推断所属任务的最终负荷结果"（弱标签/多实例学习范式），这是学界主流做法（已联网核实：RAMC-Net 2026、飞行员MWL监测2s窗口等均如此），但需诚实标注为弱标签评估，评估时必须按 `sample_id`（被试-任务）分组做 GroupKFold，禁止窗口级随机划分（会导致数据泄漏、指标虚高）。
- **窗口粒度**：由四模态中最脆弱的两个（心率~4.6秒/点，操作日志为稀疏事件，30秒窗口内仍有约66%窗口是"零动作"空窗）决定下限。5秒窗口下心率和日志基本结构性失效，已放弃。当前计划做 **10秒（不重叠，step=10s）** 与 **30秒（历史基线口径）** 两版并行对比。
- **特征工程**：不沿用历史的58个特征清单（那是历史脚本自定义未附依据的筛选结果），需重新论证再选择。EEG频段范围（delta/theta/alpha/beta/gamma）是行业通用惯例可以沿用，但"选哪些脑区/哪些频段/哪些统计量"要重新给出依据。
