# 10秒窗口_不重叠版 说明

## 生成参数

```bash
python step1_build_window_samples.py --data-dir ../../../data --output-dir ../10秒窗口_不重叠版 --window-sec 10 --step-sec 10
python step2_add_log_features.py --data-dir ../../../data \
  --index-csv ../10秒窗口_不重叠版/index.csv \
  --sample-dir ../10秒窗口_不重叠版/window_features_10s_step10s \
  --output-dir ../10秒窗口_不重叠版/加入日志特征
```

- **窗口大小 10 秒，步长 10 秒（不重叠）**——每个时刻只属于一条样本。
- 数据源全部来自 `../../../data/`（新的权威原始数据，26名被试）。

## 心率特征在10秒窗口下的可用性（关键验证）

| hr_n（窗口内心率点数） | 窗口数 | 占比 |
|---|---:|---:|
| 0点 | 569 | 8.9% |
| 1点 | 1133 | 17.8% |
| 2点 | 3579 | 56.3%（最多） |
| 3点 | 1075 | 16.9% |
| 4点 | 3 | 0.05% |

- `hr_mean` 缺失率 8.9%（仅0点窗口无法算均值）
- `hr_std` / `hr_slope_bpm_per_min` 缺失率 26.8%（0点和1点窗口都无法算标准差/斜率，需要至少2点）
- 这与此前"10秒窗口约2个心率点，勉强可算std"的理论预测一致，得到了实测验证。

- `加入日志特征/`：第二步产出，在上面基础上补充32个日志特征，**这是当前最终可用的版本**
