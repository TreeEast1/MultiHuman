# 当前 NASA 84 样本上的综合绩效 S

在最新 NASA 实验（`classification_task_level_nasa` / `regression_task_level`，84 条被试–任务）上，按历史最终公式回算自定义绩效 S。S **不是**新的官方量表，而是 NASA 反向分与关键子任务完成率的加权合成。

## 公式

```
nasa_reverse      = 1 - y_nasa / 10
weighted_step     = 0.75 * key_completion + 0.25 * nonkey_completion
S                 = 0.40 * weighted_step + 0.60 * nasa_reverse
```

- `y_nasa`：当前实验任务级 NASA-TLX 加权总分（范围约 1.33–7.80）。
- 关键子任务：`任务序列完成统计.xlsx` 黄表头列；步骤值 ≥0.5 记 1，否则记 0。
- 若某任务只有关键或只有非关键列，该侧权重归一为 1（任务 5 与 5_6 的列全部为关键）。
- 重复测量（`_repeat_*`）共用该被试–任务的步骤分，但保留各自的 `y_nasa`，因此 S 可以不同。

## 覆盖

- NASA 样本：84
- 成功配上步骤分：84 / 84
- 未匹配：无
- 重复测量条数：5

## S 分布

- 范围：[0.2171, 0.9200]
- 均值 ± 标准差：0.5673 ± 0.1633
- NASA 三分位阈值：低 ≤ 4.267，中 ≤ 5.733
- S 三分位阈值（绩效高/中/低对应 S 高/中/低）：低 ≤ 0.510，中 ≤ 0.640
- S 与 NASA Spearman ρ = -0.695（期望为负：负荷越高，绩效 S 越低）
- S 与 NASA Pearson r = -0.720
