# 窗口化 64 维 + 圣袁流程，直接预测 S

按子伟：用做 NASA 的那 64 个输入，**不要**再对窗口求平均/标准差，把切好的窗口表直接送进圣袁流程（被试内标准化 → ANOVA → 四模态定额 → 多算法 → 模态组合）。

划分仍是圣袁那套按人五折（考试人与 `compute_s_from_xgb_nasa.py` 相同）。

| 折 | 考试被试 |
|---|---|
| 1 | 2,7,12,16,23 |
| 2 | 1,6,11,17,22,26 |
| 3 | 5,10,15,21,25 |
| 4 | 4,9,14,20,24 |
| 5 | 3,8,13,18,19 |

输入：12624 窗 × 64 列。主指标 = 窗口预测按任务取中位数，再和 84 条真 S 比 R²。
