# S 预测任务：从原始数据到结果

这篇只讲 **绩效 S** 这条线。一句话：先用多模态数据预测这次任务的 NASA 负荷，再和真实步骤完成情况按 **0.7 / 0.3** 合成预测版 S。最终和真实 S 对上的程度是 **R² 0.98**。

不是另训一个「直接猜 S」的模型。S 里的步骤分用真实操作记录，只有 NASA 那一块是模型预测的。

---

## 1. 原始数据

实验 26 人，对齐后 **84 次被试–任务**（每人大约 3 个任务，含少量重复测量）。四路原始记录都在 `data/`：

| 模态 | 原始文件 | 记的是什么 |
|---|---|---|
| NASA-TLX | `data/01_NASA_TLX/NASA_TLX_原始评分_26被试82条.xlsx` | 任务后问卷，六维加权总分（大约 1.33–7.80） |
| 脑电 | `data/04_EEG/raw_set_256Hz/` | 预处理后的 EEGLAB `.set`，分析用 256 Hz、约 30 通道 |
| 心率 | `data/03_心率/心率_逐点时序_26被试.xlsx` | 手环逐点心率 |
| 眼动 | `data/05_眼动/raw_tsv/` | Tobii 导出的注视/扫视/瞳孔等 |
| 操作日志 | `data/06_任务表现与操作日志/` | 模拟机操作记录；步骤对错在 `任务序列完成统计.xlsx` |

NASA 加权总分原样当标签，不在代码里重算权重。步骤表黄表头 = 关键子任务；格子 ≥0.5 记成功，否则失败。

---

## 2. 数据处理

### 切窗

一次任务的连续信号切成：

- 窗长 **30 秒**
- 步长 **5 秒**（相邻窗重叠 25 秒）

一次任务大约 150 段（少的 3 段，多的 463 段）。每一段先算 66 个窗口指标：脑电功率、心率、瞳孔/注视、AOI、眨眼、本窗操作次数等。脑电再按「这个人自己的平均和波动」做成 z 分数。脚本在 `工作目录/01_预处理/scripts/`（step1 → step2 日志 → step3 眨眼和 EEG 标准化）。

### 收成任务级表

每个窗口指标在一次任务的所有窗上再收 4 个数：

- `__mean` 平均水平
- `__std` 稳不稳
- `__median` 中位数
- `__slope` 越做是变强还是变弱

66 × 4 = **264 列**。模型输入是 **84 行 × 264 列**。  
列名和白话含义见 [特征清单_264维.md](../特征清单_264维.md)。

没有把「任务编号」做成特征，AOI 也不用具体按钮名，避免模型靠任务类型作弊。

### 真实 S 怎么标

对每一次任务：

```
步骤分 = 0.75 × 关键子任务完成率 + 0.25 × 非关键完成率
         （只有关键或只有非关键时，那一侧权重改成 1）
NASA反向 = 1 − NASA加权总分 / 10
真实 S   = 0.70 × 步骤分 + 0.30 × NASA反向
```

S 越高 = 绩效越好（步骤做对得多，或负荷不重）。

## 3. 训练：先预测 NASA

| 项 | 设置 |
|---|---|
| 输入 | 84 × 264 |
| 要预测的 | NASA 加权总分（连续分） |
| 怎么划分 | 26 人分成 5 堆；每次 4 堆人训练，留下 1 堆人当没见过的新被试来考；换着堆考完 |
| 特征筛选 | **只在训练的人里** 用互信息（MI）挑 30 列，再拿去考 |
| 模型 | XGBoost 回归 |
| 树相关配置 | `max_depth=2`，`n_estimators=500`，`learning_rate=0.02`，`reg_lambda=2.0`，`subsample=0.8`，`colsample_bytree=0.8`，`tree_method=hist` |
| 随机种子 | `random_state=0` |

这就是现行 NASA 回归最好的那套（MI Top-30 + 浅树 XGB）。每个人的 NASA 预测，都来自「没见过这个人」的那一轮，不是把训练拟合值再塞回去。

这一步本身大约 **R² 0.52**（猜负荷有中等把握）。

脚本：`工作目录/03_建模/s_score_from_nasa84/compute_s_from_xgb_nasa.py`  
（复用 `regression_task_level` 的数据和 `common/exp_utils.py` 里的按人划分。）

---

## 4. 评测：用预测 NASA 合成 S

对同一条任务：

```
预测 S = 0.70 × 真实步骤分 + 0.30 × (1 − 预测NASA / 10)
```

步骤分两边相同，所以预测 S 和真实 S 的差别，只来自 NASA 猜偏了多少，再乘上 0.30。

评测口径：84 条都拿「没见过这个人」时的预测 NASA 来合成，再和真实 S 比 **R²**。

---

## 5. 结果（现行超参数）

**步骤 0.7 + NASA 0.3 → 预测 S 的 R² = 0.98**

| 步骤 : NASA | 预测 S 大约范围 | 均值 | R² |
|---|---|---:|---|
| 0.4 : 0.6 | 0.25–0.88 | 0.57 | 0.84 |
| 0.5 : 0.5 | 0.23–0.90 | 0.59 | 0.91 |
| 0.6 : 0.4 | 0.22–0.92 | 0.60 | 0.95 |
| **0.7 : 0.3** | **0.19–0.94** | **0.62** | **0.98** |

步骤占得越多，R² 越高，因为步骤没有拿模型去猜。改权重 **不会** 改变 NASA 那条 R² 0.52。

84 条明细：`output_from_xgb_nasa/s_from_xgb_nasa.csv`（`S_xgb` / `S_true` 就是 0.7/0.3）。

## 6. 复现

```bash
cd 工作目录/03_建模/s_score_from_nasa84
uv run --with pandas --with openpyxl --with numpy python compute_s.py
uv run --with xgboost --with pandas --with numpy --with scikit-learn python compute_s_from_xgb_nasa.py
```

流程串起来就是：

```
原始 EEG / 心率 / 眼动 / 日志 / NASA 问卷 / 步骤表
        → 30s 窗、5s 步 → 66 个窗口指标
        → 任务内 mean/std/median/slope → 84 × 264
        → 按人 5 堆划分，训练折内 MI Top-30 + XGB
        → 得到预测 NASA
        → 0.7 × 真实步骤 + 0.3 × NASA反向  → 预测 S
        → 和真实 S 比，R² 0.98
```
