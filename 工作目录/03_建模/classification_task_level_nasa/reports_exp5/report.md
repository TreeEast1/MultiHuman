# P5 NASA 三分类：多模态感知特征筛选

**硬约束**：最终输入必须同时保留 4 个维度（眼动/脑电/心率/行为）

**模态划分**（按用户语义）：
- 心率: 20 特征
- 眼动: 84 特征
- 脑电: 112 特征
- 行为: 48 特征

**设置**：84×264，StratifiedGroupKFold(5) by subject，pooled 指标
**默认模型**：XGB(d3,lr0.02,λ5,n300)（P4 最佳）
**排序方法**：折内 MI

**参考基线**：
- P0 Full + XGB = 0.750
- P1 minus_EEG + XGB = 0.809（全量152特征，去EEG）
- P4b 稳定15+MI5 = **0.810**（20特征，无EEG/HR）
- P4b 固定15+极强正则 = **0.810**（15特征，无EEG/HR）

> 注：P4 最佳方案**未保留 EEG/HR**，违反多模态约束。本实验目标：在满足约束下尽量逼近或超越 0.810

## 5. 最佳配置详情

**Stage 3 最佳**：P4-15 + EEG2 + HR2

- 总特征数：**19**
- pooled Acc = **0.786**
- pooled Macro-F1 = **0.787**
- fold F1 = 0.784 ± 0.079

**对比**：
- vs P4b 最佳(0.810，无约束)：-0.023
- vs P1 minus_EEG(0.809，去EEG)：-0.022
- vs P0 baseline(0.750)：+0.037

## 6. 结论

1. **多模态约束下的最佳 Macro-F1 = 0.787**，使用 19 个特征（覆盖4个维度）
2. **EEG 模态最优 K = 2**，HR 模态最优 K = 2
3. **眼动模态最优 K = 8**，行为模态最优 K = 12
4. 即便强制保留 EEG/HR，特征筛选后仍能达到接近 0.810 的水平
