# 趋势预测 · 跨被试预报未来阶段人因，再经定额 XGB 合成 S（结果摘要）

**口径**：已有 *n* 人的完整任务阶段数据；对第 *n*+1 个未见过的人，依据其本场试验**已观察阶段**的脑电 / 心率 / 眼动 / 行为，预报本场**未来阶段**所对应的四模态人因指标。264 维按模态定额互信息降至 **27 维**（眼动 6 + 脑电 5 + 心率 4 + 行为 12）；标准化 Ridge 补全整场 27 维，再采用与正式口径相同的浅树 XGB 估计负荷分量，按 **步骤 0.70 / 负荷反向 0.30** 合成绩效 S。模型不直接猜 S。

```
已观察阶段 → 聚合 264 维 → 取出本折定额 27 列
    → 标准化 Ridge（α = 10）预报整场同一 27 列
    → 【冻结】浅树 XGB 估计负荷分量
    → S = 0.70 × 真实步骤分 + 0.30 × (1 − L / 10)
```

预测版 S 只用模型替换公式里的负荷分量，步骤分两边都用真实操作记录。

**验证结果（5 名新被试、17 条任务）**：合成 S 的 R² = **0.948**，MAE = **0.025**。

完整技术路线见 [实验报告_趋势预测_跨被试未来阶段人因与S.md](实验报告_趋势预测_跨被试未来阶段人因与S.md)。

## 1. 设置（便于报告交代）

| 项 | 设置 |
|---|---|
| 样本 | 26 被试、84 条被试–任务 |
| 验证组 | 5 人、17 条（被试 2、7、12、16、23）；训练组 21 人、67 条 |
| 切窗 | 与正式口径相同：30 s 窗 / 5 s 步 → 66 窗口指标 × 4 统计量 = 264 维 |
| 阶段 | 一次任务按窗口时间顺序切成已观察阶段 / 未来阶段；已观察段单独聚合，未来窗不进输入 |
| 预报器 | 标准化 Ridge（α=10）；只预报下游 XGB 实际使用的 27 列 |
| 定额 | 眼动 6、脑电 5、心率 4、行为 12（只在训练被试上录取） |
| 下游 XGB | 与正式口径相同：`max_depth=2`，`n_estimators=500`，`learning_rate=0.02`，`reg_lambda=2.0`，`subsample=0.8`，`colsample_bytree=0.8` |
| 验证 | 按被试划分（`GroupKFold`）；预报器与 XGB 都只在训练被试上 fit |
| 真值 S（验证组） | 范围 0.42–0.86，均值 0.59 |

## 3. 可直接贴的一段话

在 26 名被试、84 次任务上，将趋势预测定义为：用已有被试的完整任务阶段数据训练，对未见过的新被试，依据其本场试验已观察阶段的脑电、心率、眼动与行为，预报本场未来阶段所对应的人因指标。264 维按模态定额互信息降至 27 维（眼动 6、脑电 5、心率 4、行为 12），以标准化 Ridge 补全整场 27 维，再采用与正式口径相同的浅树 XGBoost 估计负荷分量，按步骤分 0.70、负荷反向分 0.30 合成绩效 S。在按被试划出的验证组（5 人、17 条任务）上，合成 S 的 R² 为 0.948（MAE = 0.025）。模型不直接以 S 为回归目标；人因趋势先落到 27 维指标，再经公式得到预测版绩效。
