# 下一阶段人因预报：结果与选用

评测日期：2026-08-29。协议见 [PROTOCOL.md](../PROTOCOL.md)。全表见 [COMPARISON.md](COMPARISON.md)。

口径（务必一起读）：

- 下游 XGB 与正式 27 维定额方案相同。考试折只替换 264（或 27）维输入。
- **人因预报看 NASA R²**。S 含 70% 真实步骤分，R² 会系统性偏高（0.93–0.97），不能当「预报已经准到 0.97」。
- Oracle：把**真实全任务 264** 送进同一套 XGB，NASA R² = **0.528**（与正式口径 ~0.55 对齐）。这是两段式的上限。
- Early-only（观察 50%）：把前半段聚合当成整次任务，NASA R² = **0.129**。预报器必须超过它才算有用。
- 任务内切段可用 82 / 84 条（2 条窗口 < 8，无法切段）。

**主报：`reports/v8_quota27_space/models/ridge_scaled/`**

做法：每折在训练被试上用真 264 按互信息定额选出 27 列；用前半段这 27 列的 Ridge 去预报「全任务这 27 列」；再交给冻结 XGB。只动下游真正用到的列，比预报全部 264 更稳。

不要把 S R² 0.966 写成「下一阶段绩效已经预报准了」。相对正式口径（完整观测 264 时 S R² 0.979），这里的损失全部来自 NASA 从 0.53 掉到 0.26。

## 4. 数据诊断里已经预告的事

见 `00_diagnose/report.md`：

- 相邻 5s 窗（重叠 25s）滞后相关 0.85–0.90，**不能**当「下一阶段可预报」的证据。
- 隔 30s（hop=6）后，眼动/脑电相关掉到 ~0.15，行为 ~0，心率 ~0.32。窗级滚动先天就难。
- 前半段 vs 后半段：眼动均值还能沿用（Pearson 0.73），行为沿用很差（操作阶段变了）。
- S 与步骤分相关 0.977：步骤不进模型时，S 的 R² 会被步骤锁死。

## 5. 限制（写进报告）

1. EEG 的被试内 z 分数在预处理时用了该人**全部窗口**，含本任务后半段。与现有正式 XGB 输入一致，所以主实验沿用；真正在线部署应改为只用已发生窗口做 z 分数。
2. 步骤分仍用任务结束后的真值。若要在任务中途给 S，还需要另做步骤完成率的在线估计（本轮未做）。
3. 跨任务「下一场」不是同一情景的下一幕，58 对样本上没有可用的人因迁移。
4. Oracle 0.528 做不到：后半段仍有独立信息，前半段预报只能拿到大约一半。
