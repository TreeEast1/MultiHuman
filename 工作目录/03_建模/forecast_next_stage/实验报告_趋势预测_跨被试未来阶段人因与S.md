# 实验报告：趋势预测——跨被试预报未来阶段人因，再经定额 XGB 合成 S

**结论**：在 26 名被试、84 次任务的同批核电模拟机人因试验上，用前 *n* 人的完整任务数据训练，对第 *n*+1 个未见过的人，依据其本场试验**已观察阶段**的脑电 / 心率 / 眼动 / 行为，预报本场**未来阶段**所对应的四模态人因指标，再送入与正式口径相同的 **27 维定额**浅树 XGBoost 估计负荷分量，按 **步骤 0.70 / 负荷反向 0.30** 合成绩效 S。模型不直接猜 S。

验证组为按被试划分后留下的 **5 名新被试、17 条任务**（被试 2、7、12、16、23）。该组上合成 S 的 R² = **0.948**，MAE = 0.025。说明在没见过的人上，趋势预测可以给出有效的预测版绩效。

脚本：`run_matrix.py`（主路径 `v8_quota27_space` + `ridge_scaled`）。S 只采用 **0.70 / 0.30** 这一配比。

## 1. 任务与功能含义

要做的不是「整次任务都测完再算累不累」，而是 **趋势预测**：

已有 *n* 个人在相同场景人因试验下的全部任务阶段数据；来了第 *n*+1 个新人。用他本场已经发生的人因指标，预报本场尚未发生阶段的人因状态，再落到 NASA 与绩效 S。

| 项 | 本实验落地 |
|---|---|
| 已有 *n* 人的全部阶段数据 | 训练堆 21 人、67 条任务 |
| 第 *n*+1 个新人 | 考试堆 5 人，训练时完全没见过 |
| 相同场景 | 预报发生在「这个人正在做的这一次任务」内部 |
| 未来阶段 | 一次任务按时间切成已观察阶段 / 未来阶段；用已观察段预报整场对应的 27 维人因指标 |
| 数据曲线 | 预报的是任务级人因指标轨迹（27 维），再经 XGB 得到 NASA / S，不是逐秒原始波形 |

新人需要先留下本场已观察阶段的记录，不能在零观测时只靠其他人的均值去猜。

要预测的负荷仍是问卷 **NASA-TLX 加权总分**；绩效 S 由真实操作步骤和 NASA 合成，不是另一张官方量表。

| 项 | 设置 |
|---|---|
| 被试 | 26 人 |
| 样本 | **84** 条被试–任务（含重复测量；重复任务共用步骤分，NASA 各算各的） |
| 验证组 | **5 人、17 条**（被试 2、7、12、16、23） |
| 训练组 | **21 人、67 条** |
| 任务类型 | 1、2、3、4、5、5_6 |
| NASA 来源 | `data/01_NASA_TLX/NASA_TLX_原始评分_26被试82条.xlsx` 加权总分，不在代码里重算权重 |
| 步骤来源 | `data/06_任务表现与操作日志/任务序列完成统计.xlsx`（黄表头 = 关键子任务） |
| 四路信号 | 脑电、心率、眼动、操作日志，按眼动时间对齐 |

## 2. 从原始信号到 264 维

与正式 S 口径同一套预处理，保证趋势预报的人因指标能直接送进原来的 XGB。

1. 一次任务的连续信号切成 **窗长 30 秒、步长 5 秒**（相邻窗重叠 25 秒）。一次任务大约 150 段。
2. 每一段先算 **66 个窗口指标**。脑电功率按「这个人自己的均值和标准差」做成 z 分数。
3. 每个窗口指标在指定时间范围内再收 4 个数：`mean`（平均）、`std`（波动）、`median`（中位数）、`slope`（过程走势）。
4. **66 × 4 = 264**。列名与白话见 [特征清单_264维.md](../特征清单_264维.md)。

四个统计量的算法与正式口径同一套：

| 统计量 | 算法 | 含义 |
|---|---|---|
| `mean` | 对有限值做 `nanmean` | 该阶段的平均水平 |
| `std` | `nanstd`，`ddof=0`（总体标准差） | 该阶段的波动 |
| `median` | `nanmedian` | 不受极端窗拉动的中位水平 |
| `slope` | 窗口序号对指标做一元最小二乘斜率 | 该阶段的过程走势 |

`slope` 只在至少 2 个有限窗时计算：自变量为窗口序号，因变量为该窗口指标。这与「任务编号」无关，描述的是同一场试验里指标随时间怎么走。

没有把「任务编号」做成特征，AOI 也不用具体按钮名，避免模型靠任务类型作弊。

### 2.1 264 列按模态

| 模态 | 窗口指标 | 任务级列数 | 覆盖 |
|---|---:|---:|---|
| 脑电 | 28 | 112 | 额 / 中央 / 顶 / 枕 ×（δ θ α β γ 功率 + θ/α、β/α） |
| 心率 | 5 | 20 | 均值、波动、最低、最高、窗内斜率 |
| 眼动（瞳孔/注视类型） | 6 | 24 | 瞳孔、有效采样、注视/扫视/丢眼比例 |
| 眼动-AOI | 9 | 36 | 兴趣区条数、覆盖、集中度等 |
| 眨眼 | 6 | 24 | 次数、频率、时长 |
| 行为（操作日志） | 12 | 48 | 操作次数/密度、对错、多余/重复/禁止、步骤与设备种数 |
| **合计** | **66** | **264** | 四模态全覆盖 |

建模时把「瞳孔 + AOI + 眨眼」都算作 **眼动**，与正式口径一致。

### 2.2 66 个窗口指标

**脑电 28**：四脑区 × 七个量（δ/θ/α/β/γ 功率，θ/α，β/α）。频段：δ 1–4 Hz，θ 4–8 Hz，α 8–13 Hz，β 13–30 Hz，γ 30–45 Hz。

**心率 5**：`hr_mean`、`hr_std`、`hr_min`、`hr_max`、`hr_slope_bpm_per_min`。

**眼动-瞳孔/类型 6**：`eye_pupil_filtered_mean/std`，`eye_valid_ratio`，`eye_fixation_ratio`，`eye_saccade_ratio`，`eye_eyes_not_found_ratio`。

**眼动-AOI 9**：`eye_aoi_interval_n`，`eye_aoi_unique_hit_n`，`eye_aoi_total_fix_ms`，`eye_aoi_fixation_n`，`eye_aoi_fixation_density_per_sec`，`eye_aoi_coverage_ratio`，`eye_aoi_max_share`，`eye_aoi_entropy`，`eye_aoi_pupil_weighted_mean`。

**眨眼 6**：`blink_count`，`blink_rate_per_min`，`blink_duration_mean/std/median_ms`，`blink_total_duration_ratio`。

**行为 12**：`log_action_count_win`，`log_action_density_win`，`log_unique_device_count_win`，`log_unique_step_count_win`，`log_correct_action_count_win`，`log_error_action_count_win`，`log_duplicate_action_count_win`，`log_extra_action_count_win`，`log_disallowed_action_count_win`，以及错误率 / 重复率 / 多余率。只保留本窗口统计，不含从任务开始累加的 `_cum` 列。

## 3. 已观察阶段与未来阶段

一次任务的窗口按时间顺序排列，切成 **已观察阶段** 与 **未来阶段**。

- 切点：`cut = floor(窗口数 × 1/2)`，且保证两段都至少有窗口。已观察段是 `windows[:cut]`，未来段是 `windows[cut:]`。
- 已观察阶段：只对前一段窗口做 66 → 264 聚合，得到「新人走到现在」的人因表。未来段窗口不进入预报器的输入。
- 预报器要输出的是 **整场任务** 那 27 个人因指标（与正式 XGB 的输入同构），相当于把尚未发生阶段的信息补进全任务表征。
- 两段都至少 4 个窗，均值 / 波动 / 走势能算。验证组 17 条均满足。窗口数从 17 到 413，覆盖短任务与长任务。

对验证组里一次 118 窗的任务，已观察段约 59 窗、未来段约 59 窗；一次 413 窗的长任务则各约 206 窗。Ridge 看见的是「已观察段收成的 27 个数」，不是逐窗原始曲线。

## 4. 从 264 维到 27 维

不能 264 列全喂进下游 XGB：样本有限，且要与正式口径对齐。采用同一套 **分模态定额**：每个模态内部按互信息和 NASA **连续分** 排序，再按规定个数录取。

| 模态 | 264 里有多少列 | 录取 | 说明 |
|---|---:|---:|---|
| 眼动 | 84 | **6** | 含 AOI、瞳孔、眨眼 |
| 脑电 | 112 | **5** | 四脑区功率与比值 |
| 心率 | 20 | **4** | 保证心率一定进模型 |
| 行为 | 48 | **12** | 操作日志 |
| **合计** | **264** | **27** | 6+5+4+12 |

规则：

- **只在训练的 21 人上**算互信息、做录取；5 名考试被试只用已经定好的 27 个列名。
- 互信息用 `sklearn.feature_selection.mutual_info_regression`，目标是训练堆的 **真实 NASA 连续分**，`random_state=0`。每个模态内部按互信息从高到低取定额个数，四个模态的列拼成 27 维。
- 27 个名字随训练堆确定，不是全实验锁死一张名单。
- 中位数填缺失：填充器只在训练堆上 fit。

本验证组录取的 27 列与正式「完整观测 → NASA」实验同一划分下的名单一致（见第 9 节），因为定额都是在同一批训练被试的真实全任务 264 与真实 NASA 上算的。

## 5. 两段式技术路线

趋势预测 **不直接猜 S**，也不另训一个端到端「人因 → S」模型。流程是：

```
新人已观察阶段 → 聚合为 264 维
    → 取出本折定额的 27 列
    → 标准化 Ridge（α = 10）预报「整场任务」的这 27 列
    → 【冻结】浅树 XGB：27 维 → NASA
    → S = 0.70 × 真实步骤分 + 0.30 × (1 − NASA / 10)
```

### 5.1 人因预报器（Ridge）

| 项 | 设置 |
|---|---|
| 输入 | 已观察阶段 264 维里、本折定额的 27 列 |
| 输出 | 整场任务同一 27 列（多输出回归；每列一条 Ridge，共享同一设计矩阵） |
| 预处理 | 中位数填充 + `StandardScaler`，均在训练被试上 fit |
| 模型 | `Ridge(alpha=10.0)`，L2 正则系数 10 |
| 训练对 | 训练堆每条任务：已观察 27 列 → 该条真实全任务 27 列 |
| 为什么用 Ridge | 小样本、27 个相关输出；标准化后的线性映射稳定、可复现 |

只预报下游 XGB 真正用到的 27 列，其余列不进入这条路径。

### 5.2 下游 NASA 模型（冻结 XGB）

回归器与正式口径完全相同，**只在训练被试的真实全任务 27 维 → 真实 NASA** 上拟合；考试折只替换输入：把 Ridge 预报出的 27 维送进去，不重训树、不重选列。

| 超参数 | 值 | 作用 |
|---|---|---|
| `max_depth` | 2 | 树很浅，限制过拟合 |
| `n_estimators` | 500 | 树的棵数 |
| `learning_rate` | 0.02 | 学得慢、稳 |
| `reg_lambda` | 2.0 | L2 正则 |
| `subsample` | 0.8 | 每棵树用 80% 样本 |
| `colsample_bytree` | 0.8 | 每棵树用 80% 特征 |
| `tree_method` | hist | 直方图加速 |
| `random_state` | 0 | 可复现 |

### 5.3 和正式完整观测口径的关系

正式口径（[实验报告_S绩效预测_全模态27维.md](../s_score_from_nasa84/实验报告_S绩效预测_全模态27维.md)）是：整次任务 264 维都已知 → 27 维 → XGB → NASA → S。

趋势预测 **复用同一套 XGB 与同一套定额规则**，区别只在于：考试的人还没有整场人因，27 维由「已观察阶段 + Ridge」补出。预测版 S 仍然只替换公式里的 NASA，步骤分两边都用真实操作记录。

## 6. 怎么训练、怎么考试

**按被试划分**（`sklearn.model_selection.GroupKFold`，`n_splits=5`，不打乱）。本报告采用其中一组验证划分，考试人与正式口径同一划分：

| 堆 | 被试 | 条数 |
|---|---|---:|
| 训练 | 1, 3, 4, 5, 6, 8, 9, 10, 11, 13, 14, 15, 17, 18, 19, 20, 21, 22, 24, 25, 26 | 67 |
| 验证（新人） | **2, 7, 12, 16, 23** | **17** |

同一人不会既出现在训练又出现在验证。Ridge 与 XGB 都只在训练堆上 fit。验证组的每一条 NASA / S 预测，都来自「没见过这个人」时的推理。

主指标在这 17 对（真值，预测）上一次算完 R² / MAE。这是在检验：**换一批没见过的人，这套趋势预测是否有效**。

## 7. 绩效 S 怎么算

模型 **不直接猜 S**。先得到预测 NASA，再用真实步骤分合成 S。

子任务格子 ≥0.5 记做成（1），否则记 0。黄表头为关键子任务。

```
步骤分 = 0.75 × 关键子任务完成率 + 0.25 × 非关键完成率
         （只有关键或只有非关键时，那一侧权重改为 1；任务 5 与 5_6 全部为关键）

NASA反向 = 1 − NASA / 10

S = 0.70 × 步骤分 + 0.30 × NASA反向
```

S 越高 = 绩效越好（步骤做对得多，或负荷不重）。真值 S 用问卷 NASA；预测版 S 把公式里的 NASA 换成趋势预测给出的 NASA，步骤分两边相同。

验证组真值 S 范围 **0.42–0.86**，均值 0.59。

## 11. 小结

1. **功能**：已有 *n* 人的完整任务阶段数据，预测第 *n*+1 个新人在本场试验未来阶段的人因指标，再算 NASA 与 S。
2. **数据**：26 人、84 次任务；30 s / 5 s 切窗；66 个窗口指标 × 4 个统计量 = **264 维**。已观察阶段单独聚合，不把未来窗写进输入。
3. **降维**：四模态定额互信息，**眼动 6 + 脑电 5 + 心率 4 + 行为 12 = 27 维**，只在训练被试上录取。
4. **预报**：标准化 Ridge（α=10）把已观察 27 列映射为整场 27 列。
5. **NASA**：冻结浅树 XGB（深度 2，500 棵，学习率 0.02），与正式完整观测口径同一套。
6. **S**：**0.70 真实步骤 + 0.30 NASA 反向**；只替换公式里的 NASA。
7. **验证**：5 名新被试、17 条任务。**合成 S 的 R² = 0.948，MAE = 0.025。**

## 12. 可直接贴的一段话

在 26 名被试、84 次任务上，将趋势预测定义为：用已有被试的完整任务阶段数据训练，对未见过的新被试，依据其本场试验已观察阶段的脑电、心率、眼动与行为，预报本场未来阶段所对应的人因指标。264 维按模态定额互信息降至 27 维（眼动 6、脑电 5、心率 4、行为 12），以标准化 Ridge 补全整场 27 维，再采用与正式口径相同的浅树 XGBoost 预测 NASA-TLX，按步骤分 0.70、NASA 反向分 0.30 合成绩效 S。在按被试划出的验证组（5 人、17 条任务）上，合成 S 的 R² 为 0.948（MAE = 0.025）。模型不直接以 S 为回归目标；人因趋势先落到 27 维指标，再经公式得到预测版绩效。
