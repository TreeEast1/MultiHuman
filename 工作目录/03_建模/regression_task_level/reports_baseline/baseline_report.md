# P0 任务级建模 Baseline 报告（84 行 × 264 特征，5×GroupKFold by subject）

**评估协议**
- 划分：GroupKFold(n_splits=5, groups=subject)，26 名被试分 5 折
- 主指标 **pooled MAE / R²**：所有折的测试预测拼成 84 个 (真值,预测) 后统一计算
- 参考指标 fold-mean：各折分别算再取均值，波动大仅供对照

## 数据集

- 样本数：84
- 特征维度：264
- 独立被试数：26
- NASA 范围：[1.333, 7.800]  均值 4.971  std 1.581
- 参考基线 |y - mean(y)| 均值：**1.337**（任何模型 pooled MAE 应低于此才有实质贡献）

## 解读

- 零信息基线 |y-mean(y)| = 1.337
- pooled R² > 0 才算模型真正学到了预测跨被试 NASA 的能力
- 若 pooled R² < 0：说明当前特征方案在 84 样本量下无法泛化到未见被试
- 若 pooled R² > 0 但 fold R² 波动大：说明少数被试的可预测性差异是主导误差源
