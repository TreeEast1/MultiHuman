# 分析说明

## 当前规则

1. 计算完成率时，完成率按正确完成的步骤统计；任务五/六（05_06）不强制顺序；单个步骤按金标准中的同一标题块、同一注释块或同一备选块理解；EXECUTE必须和其前面的对应操作成块匹配；错误动作数按已发生动作行统计，包含多做动作和步骤内错误动作；缺失动作、重复动作行、异常步骤比例和异常动作比例另列。
2. 计算错误动作数时，完成率按正确完成的步骤统计；任务五/六（05_06）不强制顺序；单个步骤按金标准中的同一标题块、同一注释块或同一备选块理解；EXECUTE必须和其前面的对应操作成块匹配；错误动作数按已发生动作行统计，包含多做动作和步骤内错误动作；缺失动作、重复动作行、异常步骤比例和异常动作比例另列。
3. 单个步骤按金标准中同一标题块或同一注释下的一组完整动作来理解；只有整组动作完整出现，才算完成该步骤。
4. 若步骤内部包含 EXECUTE，则 EXECUTE 必须和前面的对应操作成块匹配，不能借给前一步或后一步使用。
5. 若某条 EXECUTE 同时可能属于多个步骤，则优先看它前面同设备的操作上下文，将其归到当前正在尝试完成的那一步。
6. 若某条未匹配 EXECUTE 的前一条同设备非 EXECUTE 动作已被判为多做或错误，则该 EXECUTE 继承前一步的判定口径。
7. 严格顺序任务中，只有在进入后续正确步骤之前完整复做当前步骤，才记为重复；已完成步骤后又回头做前面步骤，按错误动作处理。
8. 若后续只做了某一步中的部分动作，或多做/少做，均不算重复步骤，统一记为错误动作。
9. 任务一、二中的功率变化速率类操作按特殊规则识别：不要求最终设置数值，也不要求该步顺序，只要识别到该类操作即可。
10. 任务一中 APA101RR 的 Slow_down 长按步骤允许多次重复，不计重复次数，也不计错误动作数。
11. 任务三的恢复步骤按金标准动作清单做步骤内无序识别：该步骤内部动作不要求顺序；清单内动作重复执行记重复动作；清单外动作记错误动作；清单未做全则记漏步。
12. 金标准中的“任意/任选/选择以下”备选块按任一完整备选完成计分。
13. 05_06 沿用旧任务五口径：不强制整体顺序，并按 517 的 05_06.txt 标准日志识别。
14. 带有“可以重复操作或不操作”的步骤按可选步骤处理，不计入完成率分母，也不计入漏做错误。

## 指标定义

- 完成率 = 已完成步骤数 / 标准步骤总数。
- 已发生错误动作数 = 多做动作数 + 步骤内错误动作数。
- 异常动作总数 = 已发生错误动作数 + 缺失动作数 + 重复动作行数。
- 总动作数 = 日志动作行数 + 缺失动作数。
- 异常动作比例 = 异常动作总数 / 总动作数。
- 缺失步骤数和缺失动作数单独统计，用来说明哪些完整步骤或底层动作未完成。
- 错误步骤数 = 出现步骤内错误动作的标准步骤数。
- 异常步骤数 = 错误步骤、缺失步骤、重复步骤去重后的总数。
- 异常步骤比例 = 异常步骤数 / 标准步骤总数。
- 步骤内错误动作数 = 属于标准步骤，但未形成有效完整步骤的动作行数；在严格顺序任务中也包括未按标准顺序形成完整步骤的动作。
- 重复次数 = 完整重复步骤的次数。
- 重复动作行数 = 被标注为重复步骤或重复动作的动作行数。
- 重复率 = 重复次数 / （已完成步骤数 + 重复次数）。
