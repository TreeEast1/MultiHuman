# data/ 原始数据说明

本目录是本项目**唯一权威的原始数据源**。所有数据均来自 `历史工作_存档_20260703/01_数据_按模态/` 下的原始文件，经核实后按模态重新整理命名。历史目录中同类数据如有多个版本，本目录只保留经核实的**覆盖范围最全、最新**的版本，不代表其他版本一定错误，仅为避免歧义只留一份权威口径。

## 核心事实

- **被试范围**：01 - 26，共 26 人。
- **任务范围**：任务 1 / 2 / 3 / 4 / 5_6（任务 5_6 在被试 01-12 记为 `5_6`，实际是原任务五/六的合并版本）。
- **任务难度**：低 / 中 / 高，具体映射见 `06_任务表现与操作日志/任务难度分级.txt`。
- **预测目标**：`NASA_TLX加权总分`（01_NASA_TLX 目录），旧的"综合S指标"方案已废弃，不在本目录中。

## 重要提醒

1. **本目录不含任何"综合S指标"计算结果**——S指标方案已被推翻，如需查阅历史S指标计算逻辑，去 `历史工作_存档_20260703/`。
2. **本目录不含任何特征工程/特征筛选结果**——特征选择方案将在 `工作目录/` 中重新设计并附带依据，不沿用历史筛选结果。
3. **EEG的PSD结果是全通道全频段的原始计算结果**，尚未做任何区域聚合或特征筛选，后续特征工程从这里或`raw_set_256Hz/`原始信号出发重新做。
4. 历史目录中曾有的 `NASA_TLX/4.15NASA_TLX.xlsx`、`SART/4.15SART.xlsx`、`眼动/date analyse/`等，均为覆盖范围更小（仅12人）或列更少的旧版子集，已确认不采用，仅在历史存档中保留备查。
